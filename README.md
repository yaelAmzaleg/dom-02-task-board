# תרגיל 2 - לוח משימות

בתרגיל הזה בונים לוח משימות: מוסיפים משימות, מסמנים אותן כבוצעו, מוחקים, מסננים ורואים כמה נשארו. הדף מתנהג כמו אפליקציה אמיתית, ו-JavaScript יוצר את כל האלמנטים של הרשימה.

**מה בונים:** רשימת משימות דינמית עם עדיפויות, סינון ומונה.
**זמן משוער:** 55 דקות.

## איך זה צריך להיראות

🎬 **[צפו בסרטון הדגמה של האתר המוכן](https://cdn.jsdelivr.net/gh/Lior3796/dom-02-task-board@main/demo.mp4)** - כך האתר צריך להתנהג כשמסיימים את כל השלבים.

## איך מתחילים

1. לוחצים למעלה על **Use this template** ← **Create a new repository**, ויוצרים ריפו משלכן.
2. עושים `git clone` לריפו החדש ופותחים אותו ב-VS Code.
3. בטרמינל מריצים פעם אחת: `npm install` (צריך Node בגרסה 20 ומעלה. בודקים עם `node -v`).
4. כותבים את כל הקוד בקובץ `script.js`. את `index.html` ו-`style.css` לא צריך לשנות.
5. כדי לראות את הדף פותחים את `index.html` עם Live Server.

## איך בודקים

```bash
npm test
```

- בהתחלה כל הטסטים אדומים (✘). כל טסט מתחיל במספר השלב שהוא בודק.
- מתחת לכל טסט שנכשל כתוב מה לא עבד.
- כשכל הטסטים ירוקים (✔) מופיעה ההודעה **✅ המשימה אושרה** ואפשר לעבור למשימה הבאה.
- טסט הבונוס מסומן בכוכב (☆ / ★). הוא לא חובה, והמשימה מאושרת גם בלעדיו.
- אחרי `git push` הטסטים רצים גם ב-GitHub (לשונית Actions). וי ירוק ליד ה-commit = המשימה אושרה.

> אל תשנו את הקבצים בתיקייה `test/`.

## מבנה של משימה ברשימה

כל משימה היא אלמנט `li` שנוצר ב-JavaScript ונראה כך:

```html
<li class="priority-high">
  <span class="text">Buy milk</span>
  <button class="delete">x</button>
</li>
```

המחלקה של ה-li היא `priority-` ואחריה הערך שנבחר ב-select (`low`, `medium` או `high`). ה-CSS כבר צובע את הפס בצד לפי המחלקה.

## שלבים

### שלב 1: הוספת משימה
שליחת הטופס (לחיצה על Add או Enter) מוסיפה משימה לסוף הרשימה. הדף לא נטען מחדש. אחרי ההוספה השדה מתרוקן וה-focus חוזר אליו. אם השדה ריק (גם אם יש בו רק רווחים) לא מוסיפים כלום, ובאלמנט `error` מופיעה ההודעה `Please type a task` (ומסירים ממנו את המאפיין `hidden`). בהוספה מוצלחת ההודעה נעלמת (מחזירים `hidden`).

### שלב 2: סימון כבוצעה
לחיצה על משימה מוסיפה לה את המחלקה `done` (קו חוצה), ולחיצה נוספת מסירה אותה.

### שלב 3: מחיקה
לחיצה על כפתור ה-x מוחקת את המשימה, בלי לסמן אותה כבוצעה. השתמשו במאזין אחד על ה-ul (event delegation) במקום מאזין לכל משימה, ובדקו עם `event.target` על מה לחצו.

רמז: `event.target.closest("li")` מחזיר את ה-li שבתוכו קרה האירוע.

### שלב 4: מונה
האלמנט `left` מציג כמה משימות עוד לא בוצעו, ומתעדכן בכל הוספה, סימון ומחיקה.

### שלב 5: סינון
שלושת הכפתורים ב-`filters` (All, Active, Done) מציגים את כל המשימות, רק את אלה שלא בוצעו, או רק את אלה שבוצעו. הכפתור הפעיל מקבל את המחלקה `active` והאחרים מאבדים אותה. משימות שלא מוצגות מקבלות את המאפיין `hidden`. בכל כפתור יש `data-filter` עם הערך המתאים, וקוראים אותו עם `event.target.dataset.filter`.

### שלב 6: ניקוי
הכפתור Clear completed מוחק את כל המשימות שבוצעו.

### שלב 7: הודעת רשימה ריקה
כשאין אף משימה ברשימה מוצג האלמנט `empty`, וכשיש לפחות אחת הוא מוסתר.

## בונוס
לא מאפשרים להוסיף משימה שכבר קיימת (בלי הבדל בין אותיות גדולות לקטנות). במקום זאת מציגים באלמנט `error` את ההודעה `This task already exists`.

## בדיקה עצמית
- הוספה, סימון ומחיקה לא טוענים את הדף מחדש.
- אחרי סימון ומחיקה המונה תואם למספר המשימות שלא בוצעו.
- סינון Done ואז הוספת משימה חדשה מסתיר את המשימה החדשה, כי היא לא בוצעה.
- מחיקת הרשימה כולה מחזירה את ההודעה No tasks yet.
